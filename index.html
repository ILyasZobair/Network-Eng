QUICK START / GUIDE

Welcome to the lab.

Construisez une petite topologie et résolvez les missions étape par étape.

  1. Ajouter un équipement : utilisez PC, Switch, Router ou Server.
  2. Relier les appareils : activez Cable mode, puis cliquez sur deux équipements.
  3. Configurer l'IP : sélectionnez un PC et renseignez IP, masque et gateway.
  4. Utiliser le terminal : tapez help, show devices, show ip, ping PC-01 ou show vlan.
  5. Valider : terminez l'objectif et cliquez sur Validate mission.

Les commandes et les tests sont simulés dans le navigateur. Aucun paquet réseau réel n'est envoyé.
